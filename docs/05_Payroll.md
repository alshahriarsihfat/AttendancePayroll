# Hourly Salary and Payroll Rules

- Daily Salary and Daily Duty Hours configurable per employee.
- Hourly Rate = Daily Salary / Daily Duty Hours.
- Partial attendance paid proportionally to payable duration.
- Meal/rest breaks included in payable duration.
- Approved overtime calculated separately.
- Historical attendance preserves salary/duty-hour snapshot; later changes do not alter past payroll.
- Rounding via existing payRound rules.
